## 功能一览

### 核心计算
- **CIDR 格式**：`192.168.10.0/23`
- **IP + 子网掩码**：`192.168.136.0 255.255.252.0`
- **单主机**：`10.1.1.1`（自动视为 /32）
- 非连续掩码识别与提示

### 计算结果
| 条目 | 说明 |
|------|------|
| 子网掩码 / 反掩码 | 十进制点分格式 |
| 网络地址 / 广播地址 | 自动按位与/或运算 |
| 可用主机范围 | 排除网络地址和广播地址 |
| 可用主机总数 | 千分位格式化 |
| 十六进制表示 | IP 和掩码的 0x 格式 |

### IP 地址归属分类
自动识别并标注 IP 地址类型：

- **公网地址**
- **私有地址**（A/B/C 类，RFC 1918）
- **回环地址**（127.0.0.0/8）
- **链路本地地址**（169.254.0.0/16）
- **多播地址**（224.0.0.0/4）
- **保留地址**

### 子网拆分（Subnet Splitting）
输入父网段后，可选择目标子网掩码长度，**自动列出所有子网详情**：

- 网络地址 / 子网掩码 / 广播地址
- 可用主机范围及主机数
- 超过 512 个子网时自动折叠并提示

### 其他特性
- 🌓 5 种皮肤 × 2 种明暗模式 = 10 种视觉组合
- ⚡ 实时计算（80ms 防抖）
- 📋 一键复制（带弹簧动画 Toast 提示）
- 🧹 输入框清空按钮
- ⌨️ 回车键即时计算
- 🎯 快速预设按钮（含常用私网网段）
- ♿ 基础无障碍支持（ARIA 标签）
- 🪟 毛玻璃粘性导航栏 + 自适应布局
- 📱 移动端响应式适配

## 使用方式

直接在浏览器打开 `cidr-calculator.html` 即可，无需任何服务端或构建工具。

### 输入格式示例

```
192.168.10.0/23          # CIDR 格式
10.1.1.1 255.255.255.0   # IP + 子网掩码
172.16.0.1               # 单主机（自动 /32）
```
